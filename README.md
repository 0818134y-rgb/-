# わちゃパ（ワードウルフ・NGワードほかパーティーゲーム集）

ブラウザで遊べるパーティーゲーム。iPhone・Android・PC で、部屋コードを使って同じ部屋に入れます。

- 遊ぶ：https://0818134y-rgb.github.io/-/
  - iPhone は Safari で開いて「共有」→「ホーム画面に追加」
- ダウンロード
  - Android アプリ（テスト版）：[download/wachapa-android-0.7.1-test.apk](download/wachapa-android-0.7.1-test.apk)
  - PC 版（遊ぶ.bat）：[download/WachapaPC-0.7.1.zip](download/WachapaPC-0.7.1.zip)

通信は PeerJS（P2P）で、自前のサーバーは使いません。ソースコードは別のリポジトリにあります。
