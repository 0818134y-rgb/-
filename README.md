# パーティーゲーム（なんでもアリーナ ほか）

ブラウザで遊べるパーティーゲーム。iPhone・Android・PC で、部屋コードを使って同じ部屋に入れます。

- 遊ぶ：https://0818134y-rgb.github.io/-/
  - iPhone は Safari で開いて「共有」→「ホーム画面に追加」
- ダウンロード
  - Android アプリ（テスト版）：[download/partygame-android-0.6.1-test.apk](download/partygame-android-0.6.1-test.apk)
  - PC 版（遊ぶ.bat）：[download/PartyGamePC-0.6.1.zip](download/PartyGamePC-0.6.1.zip)

通信は PeerJS（P2P）で、自前のサーバーは使いません。ソースコードは別のリポジトリにあります。
